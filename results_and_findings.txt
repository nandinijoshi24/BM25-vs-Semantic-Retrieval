RESULTS AND FINDINGS
====================

The retrieval quality project evaluated two retrieval approaches:
BM25 lexical retrieval and semantic retrieval using Sentence Transformers.
Both approaches were evaluated on 6,112 queries using Precision, Recall,
F1-score, and nDCG at K = 1, 3, 5, and 10.

1. PRECISION

Semantic retrieval achieved higher Precision than BM25 at every K value.

K=1:
BM25 = 0.5717
Semantic = 0.6878

K=3:
BM25 = 0.3848
Semantic = 0.4743

K=5:
BM25 = 0.3015
Semantic = 0.3628

K=10:
BM25 = 0.2159
Semantic = 0.2455

The largest Precision improvement was observed at K=1, where semantic
retrieval improved over BM25 by 0.1161.

2. RECALL

Semantic retrieval also achieved higher Recall at every K value.

K=1:
BM25 = 0.1957
Semantic = 0.2382

K=3:
BM25 = 0.3754
Semantic = 0.4655

K=5:
BM25 = 0.4698
Semantic = 0.5652

K=10:
BM25 = 0.6241
Semantic = 0.7035

The largest Recall improvement was observed at K=5, with an improvement
of 0.0954.

3. F1-SCORE

Semantic retrieval achieved a higher F1-score than BM25 at all K values.

K=1:
BM25 = 0.2916
Semantic = 0.3538

K=3:
BM25 = 0.3801
Semantic = 0.4699

K=5:
BM25 = 0.3673
Semantic = 0.4419

K=10:
BM25 = 0.3209
Semantic = 0.3640

The largest F1 improvement occurred at K=3, where semantic retrieval
improved over BM25 by 0.0898.

4. nDCG

Semantic retrieval achieved higher nDCG than BM25 at every evaluated K.

K=1:
BM25 = 0.5717
Semantic = 0.6878

K=3:
BM25 = 0.4788
Semantic = 0.5851

K=5:
BM25 = 0.5003
Semantic = 0.6043

K=10:
BM25 = 0.5649
Semantic = 0.6626

The nDCG improvement remained consistent across all K values.

5. OVERALL FINDING

The experimental results show that semantic retrieval consistently
outperformed the BM25 baseline across Precision, Recall, F1-score, and
nDCG.

This indicates that semantic retrieval was more effective at identifying
relevant passages for the evaluated dataset than the lexical BM25
baseline.

The results also demonstrate that retrieval quality depends on the
evaluation metric and retrieval depth K. Therefore, using multiple
evaluation metrics provides a more comprehensive assessment of retrieval
performance than relying on a single metric.

6. CONCLUSION

Based on the experimental evaluation, semantic retrieval provided better
overall retrieval quality than BM25 for the evaluated dataset.

The comparison demonstrates the usefulness of evaluating retrieval
systems using multiple measures including Precision, Recall, F1-score,
and nDCG.
